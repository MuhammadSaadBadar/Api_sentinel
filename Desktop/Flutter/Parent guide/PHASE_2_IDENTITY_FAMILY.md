# Phase 2 — Identity and Family

## Milestones:
2–3

## Goal:
Users, authentication, families, roles, permissions.

## Milestone 2 — Authentication Details:
- Register.
- Login.
- Logout.
- Refresh tokens.
- Email verification architecture.
- Password reset.
- User profile.

Definition of Done:
- Authenticated API requests work.
- Unauthorized requests are rejected.
- Refresh token rotation works.
- Passwords are never stored in plain text.

## Milestone 3 — Family Management Details:
- Create family.
- Join family.
- Invite member.
- Accept invitation.
- Reject invitation.
- Family member list.
- Roles.
- Permissions.

Definition of Done:
- User can create a family.
- Users can join through invitation.
- Authorization is enforced server-side.
- Family members cannot access unrelated families.
