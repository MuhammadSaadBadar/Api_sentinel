# Phase 5 — Safety

## Milestones:
8–9

## Goal:
Build push notifications and SOS/emergency functionality.

## Milestone 8 — Push Notification System Details:
- FCM integration.
- Device tokens.
- Notification service.
- Notification collection.
- Read/unread state.
- Deep links.

Definition of Done:
- Push notification reaches correct device.
- Notification opens the correct screen.
- Multiple devices are supported.
- Invalid tokens are handled.

## Milestone 9 — Emergency / SOS Details:
- SOS button.
- Emergency creation.
- Guardian notification.
- Emergency state.
- Emergency screen.
- Live emergency location.
- Acknowledge.
- Resolve.
- Emergency history.

Definition of Done:
```text
Child presses SOS
→ Emergency created
→ Authorized guardians notified
→ Emergency screen opens
→ Live location available
→ Guardian acknowledges
→ Emergency resolved
```
